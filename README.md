# 角色扮演游戏 · DeepSeek V4.1 Flash

本地运行的 React / Vite 互动小说游戏。所有生成请求只使用 DeepSeek 官方接口 `https://api.deepseek.com/chat/completions`，模型固定为 `deepseek-flash`。

## 使用

1. 双击 `启动开发服务器.bat`，或执行 `npm install` 后运行 `npm run dev`。
2. 打开 `http://127.0.0.1:3000`，填写 DeepSeek API Key，可先测试连接。
3. 粘贴或生成世界书，填写玩家角色，可选自定义第一幕。
4. 选择长文、短文或对话模式。每轮正文后完整显示状态和分层记忆。

API Key 只存于当前浏览器配置中；本机代理不持久化 Key。生成时，世界书、角色、相关记忆及近期聊天会发送给 DeepSeek。API 费用由 DeepSeek 收取。没有供应商切换、自定义模型或 Base URL，外部生图接口已停用。开发服务器与 `npm run preview` 都提供本机代理。

官方模型说明：[DeepSeek V4.1 Flash 发布公告](https://www.deepseek.com/en/news/deepseek-v4-1-flash/)。固定请求 ID 为 `deepseek-flash`，具体后端版本仍由 DeepSeek 官方管理。

## 记忆与状态

- 最近剧情：8 条，按已接受回复的先后保存。
- 长期剧情：5 组，每组最多 8 条较早事件，保留来源与顺序。
- 历史归档：轮换出的长期组继续保存在本地，可在记忆面板中查看；匹配当前行动的旧事可再次注入。
- 核心记忆：玩家手动新增或固定，不设条数上限，AI 不能修改或删除。
- 角色记录：保留已知人物的档案、关系、最后去向和离场状态。
- 当前状态：世界、概况、时间、地点、天气、玩家、在场角色、周围人物、物品与持续效果。未返回的字段沿用旧值，未知信息不强填。

模型返回正文及结构化数据，程序解析后渲染完整状态栏；不会执行输出中的 Python、HTML 或函数。状态和记忆必须一并有效才提交。缺失或损坏的数据会显示“沿用上轮”提示，取消或截断请求不写入记忆。

整局聊天、角色、世界书、记忆和状态一起保存在浏览器，刷新自动恢复。撤回上一轮同时恢复该轮之前的数据，“继续说”也可独立撤回。持久化存档保留最近 40 条消息范围内的撤回快照，较早的正文与状态展示仍保留。导出存档可保存一份不含 API Key 的 JSON 备份。

模板升级会先备份旧模板和原始记忆。叙事预设固定为代码中的当前版本，游戏不提供查看、编辑或恢复提示词的入口，浏览器中的历史自定义提示词不再读取。只有点击“新游戏”并确认才清空本局。

完整设计、协议与验证标准见 [状态栏与记忆方案](docs/状态栏与记忆方案.md)。

## 开发与验证

```sh
npm test
npm run build
npm run dev
```

`src/utils/llm/providers.js` 定义唯一模型与地址，`server/llm-proxy.js` 在转发前再次校验；`src/utils/story-prompt.js` 统一模式、上下文和数据协议；`src/utils/memory/` 负责解析、存储、分层、角色档案及回滚；`src/utils/game-session.js` 保存整局一致的快照；`StatusBar` 展示每轮快照，`MemoryTablePanel` 管理当前记忆。

测试使用模拟响应，不消耗真实 API 额度。真实联网生成仍需用户自己的有效 DeepSeek Key。叙事连贯性由模型生成与人工编辑共同维护，程序能校验结构和保存规则，不能保证所有剧情事实都准确。
